## 🚀 Quick Start (3 Steps)

### **Step 1: Install Node.js** (First time only)
1. Go to https://nodejs.org/
2. Download **Node.js LTS** (Long Term Support)
3. Install it with default settings
4. Restart your computer

### **Step 2: Download This Folder**
- Clone or download the ship-loadicator repository
- Keep all files together in one folder

### **Step 3: Run the Application**

**Windows Users:**
- Double-click `run-portable.bat`

**Mac/Linux Users:**
- Open Terminal
- Navigate to the folder
- Run: `bash run-portable.sh`

---

## 📊 What Happens Next

1. Application starts automatically
2. Browser opens to http://localhost:3001
3. Start managing your ship cargo!

## ⚙️ Configuration

Edit `.env` file to customize:

```
PORT=3001                    # Change server port
NODE_ENV=production         # Mode setting
SHIP_CAPACITY=10000        # Ship capacity in kg
```

---

## 🔧 Troubleshooting

### Problem: "Node.js not found"
**Solution:** Install Node.js from https://nodejs.org/

### Problem: "Port 3001 already in use"
**Solution:** Edit `.env` and change PORT to 3002 or 3003

### Problem: Browser doesn't open
**Solution:** Manually open http://localhost:3001

### Problem: "npm: command not found"
**Solution:** Restart your computer after installing Node.js

### Problem: Slow startup first time
**Solution:** First run downloads packages (~2-3 minutes), future runs are fast
